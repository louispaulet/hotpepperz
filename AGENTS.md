# CODEX.md

## Repo Workflow

- When making code or file changes in this repository, validate the result before finishing.
- After successful changes, commit them automatically with a concise message.
- After committing, push the current branch to `origin`.
- If the current branch is `main`, push to `origin/main`.
- If pushing is blocked by authentication, remote configuration, or branch-state issues, report the exact blocker clearly.
- Do not ask for repeated confirmation about committing or pushing unless the git operation would be destructive or ambiguous.

## Working Preference

- Prefer finishing tasks end-to-end in a single pass when possible: implement, verify, commit, and push.
- Leave unrelated local files alone unless explicitly asked to clean them up.
